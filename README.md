# Система складского учёта и инвентаризации

Веб-приложение для автоматизации складского учёта, управления партиями товаров, движениями и списаниями.

## Технологии

- **Backend**: Django + Django REST Framework
- **Frontend**: React
- **Database**: PostgreSQL
- **DevOps**: Docker + docker-compose
- **Authentication**: JWT

## Функциональность

- Управление пользователями и ролями (Admin/Manager/User)
- Учёт товаров по партиям
- Отслеживание движений товаров
- Инвентаризация складов
- Списание товаров
- Аудит действий пользователей
- Уведомления о событиях
- Отчёты и аналитика
- Экспорт данных в Excel/PDF

## Роли и доступ

| Роль | Права |
|------|-------|
| Admin | Полный доступ ко всем функциям |
| Manager | Создание и редактирование, утверждение списаний |
| User | Просмотр, создание заявок |

## Тестовые учётные данные

- **Admin**: admin / admin123
- **Manager**: manager / manager123
- **User**: user / user123
